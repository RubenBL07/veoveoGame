## 🎮 Pantallas a Capturar

### Pantallas Principales
1. **Home/Dashboard** - Pantalla principal con estadísticas
2. **Create Room** - Creación de sala de juego
3. **Game** - Pantalla de juego activo
4. **Profile** - Perfil del usuario
5. **Friends** - Lista de amigos
6. **Leaderboards** - Tabla de clasificación
7. **Premium** - Página de suscripción premium
8. **Chat** - Chat en tiempo real

### Pantallas Secundarias
9. **Public Rooms** - Salas públicas disponibles
10. **Room Lobby** - Lobby de sala antes del juego
11. **Settings** - Configuraciones de la app
12. **Achievements** - Logros del usuario

## 🎨 Guías de Diseño

### Composición
- **Enfoque:** Centrar en la funcionalidad principal
- **Elementos:** Mostrar UI limpia y moderna
- **Colores:** Resaltar la paleta de colores de la app
- **Texto:** Evitar texto pequeño o ilegible

### Capturas Atractivas
- **Acción:** Mostrar el juego en progreso
- **Interacción:** Capturar momentos de interacción
- **Animaciones:** Incluir elementos animados si es posible
- **Contexto:** Mostrar el entorno de uso real

## 📐 Especificaciones Técnicas

### Formato
- **Formato:** PNG o JPEG
- **Calidad:** Alta resolución (mínimo 72 DPI)
- **Compresión:** Optimizada para web
- **Tamaño:** Máximo 2MB por imagen

### Elementos a Incluir
- **Status Bar:** Incluir barra de estado real
- **Navigation:** Mostrar navegación de la app
- **Content:** Contenido relevante y actualizado
- **Branding:** Logo y elementos de marca

## 🎯 Consejos para Capturas Atractivas

### Preparación
1. **Limpiar la app:** Asegurar que no hay datos de prueba
2. **Configurar datos:** Usar datos de ejemplo realistas
3. **Optimizar UI:** Verificar que la interfaz esté perfecta
4. **Probar en dispositivos:** Usar dispositivos reales cuando sea posible

### Captura
1. **Iluminación:** Usar buena iluminación
2. **Ángulo:** Capturar desde ángulos naturales
3. **Momento:** Elegir el momento perfecto
4. **Múltiples tomas:** Hacer varias capturas y elegir la mejor

### Post-producción
1. **Recortar:** Ajustar a las dimensiones exactas
2. **Optimizar:** Comprimir sin perder calidad
3. **Verificar:** Revisar en diferentes dispositivos
4. **Organizar:** Mantener un sistema de archivos claro
