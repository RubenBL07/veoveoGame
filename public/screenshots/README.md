## 🎮 Pantallas a Capturar

### 1. Pantalla de Inicio (Home)
**Descripción:** Dashboard principal con gamificación
**Elementos clave:**
- Nivel del usuario y XP
- Desafíos diarios
- Botones de acción principales
- Estadísticas del usuario

### 2. Crear Sala
**Descripción:** Proceso de creación de sala de juego
**Elementos clave:**
- Formulario de configuración
- Opciones de sala (privada/pública)
- Límites de jugadores
- Configuración de idioma

### 3. Juego Activo
**Descripción:** Captura de foto y proceso de adivinanza
**Elementos clave:**
- Interfaz de cámara
- Lista de objetos detectados por IA
- Proceso de selección de objeto
- Interfaz de adivinanza

### 4. Perfil de Usuario
**Descripción:** Perfil completo con estadísticas
**Elementos clave:**
- Avatar y información personal
- Estadísticas de juego
- Logros desbloqueados
- Historial de partidas

### 5. Sistema de Amigos
**Descripción:** Gestión de amigos y solicitudes
**Elementos clave:**
- Lista de amigos
- Solicitudes pendientes
- Búsqueda de usuarios
- Gestión de amistades

### 6. Clasificaciones (Leaderboards)
**Descripción:** Rankings globales y regionales
**Elementos clave:**
- Top jugadores
- Diferentes categorías
- Posición del usuario
- Filtros por región

### 7. Temas Premium
**Descripción:** Personalización visual
**Elementos clave:**
- Galería de temas
- Temas premium destacados
- Vista previa de temas
- Opciones de personalización

### 8. Chat en Tiempo Real
**Descripción:** Comunicación durante el juego
**Elementos clave:**
- Mensajes de chat
- Indicadores de estado
- Emojis y reacciones
- Mensajes del sistema

## 🎨 Guías de Diseño

### Colores y Estilo
- **Tema:** Oscuro con acentos vibrantes
- **Colores principales:** #6366f1, #8b5cf6, #f59e0b
- **Fondo:** #1a1a1a
- **Texto:** #ffffff, #a1a1aa

### Elementos Visuales
- **Glassmorphism:** Efectos de cristal
- **Gradientes:** Transiciones suaves
- **Animaciones:** Movimientos fluidos
- **Iconografía:** Moderna y clara

### Composición
- **Enfoque:** Funcionalidad principal visible
- **Espaciado:** Generoso y limpio
- **Jerarquía:** Información importante destacada
- **Accesibilidad:** Contraste adecuado

## 📐 Especificaciones Técnicas

### Formato
- **Formato:** PNG
- **Calidad:** Alta resolución
- **Compresión:** Optimizada para web
- **Transparencia:** No permitida

### Optimización
- **Tamaño de archivo:** < 2MB por imagen
- **Resolución:** Nítida en todos los dispositivos
- **Aspect ratio:** Mantener proporciones exactas
- **Color profile:** sRGB

## 🎯 Consejos para Capturas Atractivas

### Contenido
- **Mostrar funcionalidades clave** de manera clara
- **Usar datos realistas** pero atractivos
- **Incluir elementos de gamificación** visibles
- **Demostrar la calidad visual** de la app

### Composición
- **Enfoque en la acción principal** de cada pantalla
- **Mostrar progreso y logros** del usuario
- **Incluir elementos sociales** cuando sea relevante
- **Destacar características premium** sutilmente

### Técnica
- **Usar dispositivos reales** cuando sea posible
- **Capturar en condiciones de luz óptimas**
- **Evitar reflejos y sombras** no deseados
- **Mantener consistencia** entre todas las capturas
